Información Importante

  • Formato: Solo se aceptan archivos .xlsx y .xls
  • Tamaño máximo: 10 MB
  • Campos requeridos: nombre, descripcion, precio, marca, categoria
  • Creación automática: Las marcas y categorías se crean automáticamente si no existen
  • Variantes: Si incluís un SKU, se creará una variante del producto
  • Errores: Las filas con errores se omiten, pero la importación continúa
